# Aquaventura

Psygnosis's Aquaventura (1992) under WHDLoad: the direct RawDIC slave v1.3 (22.12.2016) by
Bored Seal, updated by StingRay. Version 2.0b adds Enhanced framerate (CUSTOM1: the game's
code in fast memory, the game at the A500's pace, and frames between the game's steps as
the machine allows). The original slave is by Bored Seal and StingRay (game.conf `AUTHOR`,
`UPSTREAM`).
The repository's rules and shared docs are in the root `AGENTS.md` and `docs/index.md`;
this file and `docs/` here hold only what is specific to this game.

Read `docs/open-work.md` first.

| Doc | Read it for |
|---|---|
| `docs/open-work.md` | where the work stands and the ordered next items |
| `docs/development.md` | what differs from the shared workflow: inputs, builds, tools, the saved state, the code copy, traps |
| `docs/internals.md` | the program, game time, every slave patch, measurements, limitations |

The slave source is `src/` (`relocs.i` is generated by `tools/relocs.py`); `tools/` is the
development harness and never ships.
